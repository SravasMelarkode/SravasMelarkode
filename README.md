# Hi, I'm Sravas 👋

### Full-Stack Developer | AI/ML Enthusiast | Generative AI & MLOps 🚀

Hey there, I'm Sravas, a developer interested in building intelligent, scalable, and production-ready applications by combining full-stack engineering with Artificial Intelligence and Machine Learning.

My interests span **AI/ML, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Natural Language Processing (NLP), and MLOps**. I enjoy exploring how AI systems can retrieve relevant information, understand human language, generate useful responses, and integrate into real-world applications.

- 🤖 **AI & Machine Learning:** Exploring intelligent systems, predictive models, and data-driven solutions.
- 🧠 **Generative AI & LLMs:** Working with language models, prompt engineering, and AI-powered applications.
- 🔎 **RAG & NLP:** Interested in semantic search, embeddings, document retrieval, text processing, and context-aware AI systems.
- ⚙️ **MLOps:** Exploring model deployment, experiment tracking, reproducibility, automation, and model lifecycle management.
- 🌐 **Full-Stack Development:** Building web and mobile applications using Python, Django, JavaScript, and React Native.
- ☁️ **Cloud & Deployment:** Exploring AWS and scalable application infrastructure.
- 📈 **Continuous Learning:** Improving my skills across software engineering, AI research, and production ML workflows.

My goal is to bridge the gap between software development and AI by building applications that are useful, reliable, and scalable.
